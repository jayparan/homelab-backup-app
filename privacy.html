Privacy policy

homelab-backup is used only by its owner, with the owner's own Google account.

  • Google data accessed: only files and folders that homelab-backup created in the owner's Google Drive (Google permission drive.file). It does not read, list or change any other file.
  • Use: the owner's own server backups are uploaded to, read back from and checked in that folder. Backups are encrypted on the owner's server before upload.
  • Sharing: no data is collected, sold or shared with anyone. No analytics, no advertising, no third parties.
  • Storage: the Google sign-in token is kept only on the owner's own server. The owner can remove the app's access at any time in the Google account's security settings.
  • Contact: through the GitHub account that publishes this page.
